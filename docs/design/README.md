对话框约定（对照冻结 R1 / R3 / R4 / R12 / R13）：

- 课前用「确定本课设备」一次填完数量、交换机/路由器口数、可选预置路由口 IP；开放领取后收起。
- 领取后点 RJ45 弹「填写对端端口」（手输编号）；PC 与路由器再弹「配置 IP」。占用时报「端口已被占用」。
- 模拟模式帧到达交换机/路由器时弹「转发数据帧」，用端口按钮选出口。选错提示「端口不正确」，帧留本机。
- PC 模拟组帧不选口。发起聊天填对方 IP 仍用已有聊天对话框。TAP 对端由教师挂接，学生不弹接线框。
