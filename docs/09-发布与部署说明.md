记录日期：2026-10-03

## 1. 教室服务器：教师机本机 80，Nginx 对外 8080 托管页面

状态：已执行（Linux amd64 预编译运行包 + 系统 Nginx）。

教师机只绑 `127.0.0.1:80`，只提供 `/api` 与 `/ws`。公网打不到 80。

系统 Nginx 听 `8080`：托管 `/teacher/`、`/student/`，并把 `/api/`、`/ws` 转到本机 80。

本开发环境产物：

- `deploy/runtime/papernet-teacher`：Linux x86_64 glibc 教师机
- `deploy/runtime/teacher/`、`deploy/runtime/student/`：静态页
- `deploy/runtime/版本说明.txt`：版本、编译时间、打包时间、Git 提交
- `deploy/nginx.conf`、`deploy/papernet.service`：已入库

目标 Ubuntu 需要 amd64。ARM 跑不了这份二进制。

编产物命令（以后更新版本时在本仓库执行）：

```bash
bash scripts/pack-runtime.sh
```

在服务器上（账号不是 `ubuntu` 时改 `papernet.service` 的 `User=` 和路径）：

```bash
sudo apt-get update
sudo apt-get install -y nginx

mkdir -p /home/ubuntu/papernet-data
chmod +x /home/ubuntu/papernet-deploy/runtime/papernet-teacher

sudo mkdir -p /var/www/papernet
sudo cp -a /home/ubuntu/papernet-deploy/runtime/teacher /var/www/papernet/teacher
sudo cp -a /home/ubuntu/papernet-deploy/runtime/student /var/www/papernet/student

sudo cp /home/ubuntu/papernet-deploy/nginx.conf /etc/nginx/sites-available/papernet
sudo ln -sf /etc/nginx/sites-available/papernet /etc/nginx/sites-enabled/papernet
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx

sudo cp /home/ubuntu/papernet-deploy/papernet.service /etc/systemd/system/papernet.service
sudo systemctl daemon-reload
sudo systemctl enable --now papernet
sudo systemctl status papernet --no-pager

sudo ufw allow 8080/tcp
```

云安全组只放行 TCP `8080`，不要放行 80。访问：

- 教师端 `http://服务器IP:8080/teacher/`
- 学生端 `http://服务器IP:8080/student/`
- 健康检查 `http://服务器IP:8080/api/v1/health`

根路径没有首页。两边必须同一主机名和同一端口。

## 2. 预览用编好的静态页，少走 Vite

状态：已执行。

本环境预览可以由教师机直接托管静态页（`PAPERNET_UI_DIR`），命令：

```bash
/root/.cargo/bin/cargo build --release -p papernet-teacher
bash scripts/build-web.sh
bash scripts/preview-static.sh
```

默认 `http://127.0.0.1:8088/teacher/` 与 `/student/`。教室服务器形态仍是 Nginx 托管页面。

## 3. Windows 教室：教师机一个程序，学生用浏览器

状态：已执行（交叉编译脚本与教室包布局）。

教师电脑（Windows 10+ 64 位）跑一个文件夹：`papernet-teacher-<版本>.exe` + `teacher/` + `student/` + `启动教室.bat`。版本取自仓库 `Cargo.toml`（当前 `0.1.0`）。`使用说明.txt` 含版本、编译时间、打包时间。老师打开 `http://本机IP:8088/teacher/`，学生用浏览器打开同一地址的 `/student/`。学生不用装程序。

`file://` 打开 HTML 访问不了接口。仓库里的 `papernet-student` 是 Linux 无界面客户端。

```bash
bash scripts/pack-windows.sh
```

产物在 `deploy/windows/`（gitignore，不入库）。
