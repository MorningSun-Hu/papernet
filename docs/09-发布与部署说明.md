# 发布与部署说明

记录日期：2026-10-02

效力：发布方式与本地运行包布局。V1.2 冻结文件保持原文。Docker 打包文件与 `deploy/runtime/` 在 gitignore 中，不入库。

## 1. 资源紧张的服务器：在此编好，服务器只跑

状态：已执行（Linux amd64 预编译运行包）。当前教室服务器用「教师机本机 80 + Nginx 对外 8080 反代」，不用 Docker。

课堂运行很轻，吃资源的是编译。1–2 GB 内存用来上课通常够。

本开发环境已编出并放到 `deploy/runtime/`：

- `deploy/runtime/papernet-teacher`：Linux x86_64 glibc 教师机（约 5.4MB）
- `deploy/runtime/teacher/`、`deploy/runtime/student/`：静态页

`deploy/Dockerfile` 只从 `nginx:1.27-bookworm` 起步，COPY `runtime/` 里的产物。构建上下文是 `deploy/` 目录。服务器上 `docker compose up -d --build` 不再编 Rust/Node，第一次拉 Nginx 基础镜像后一般一两分钟。

本环境没有 Docker 守护进程，不能在这里导出镜像 tar。交给服务器的是 `deploy/` 目录（含 `runtime/`）。

目标 Ubuntu 需要 amd64。ARM 跑不了这份二进制。

在服务器上：

```bash
cd deploy
docker compose up -d --build
```

默认对外端口 `8088`，改 compose 里 `"8088:80"` 的左边数字。访问 `/teacher/`、`/student/`。根路径没有首页。

编产物命令（以后更新版本时在本仓库执行）：

```bash
/root/.cargo/bin/cargo build --release -p papernet-teacher
bash scripts/build-web.sh
mkdir -p deploy/runtime
cp target/release/papernet-teacher deploy/runtime/papernet-teacher
cp -a dist/teacher deploy/runtime/teacher
cp -a dist/student deploy/runtime/student
```

## 1.1 手动部署：教师机本机 80，Nginx 对外 8080

教师机只绑 `127.0.0.1:80`，自己提供 `/teacher/`、`/student/`、`/api`、`/ws`。公网打不到 80。

Nginx 不托管静态文件，只在 `8080` 把访问转到本机 80。浏览器仍走同一入口的 `/api` 与 `/ws`（页面需要它们）；这两条路径对外只出现在 8080。

```bash
sudo apt-get update
sudo apt-get install -y nginx

mkdir -p /home/ubuntu/papernet-data
chmod +x /home/ubuntu/papernet-deploy/runtime/papernet-teacher

sudo cp /home/ubuntu/papernet-deploy/nginx.conf /etc/nginx/sites-available/papernet
sudo ln -sf /etc/nginx/sites-available/papernet /etc/nginx/sites-enabled/papernet
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx

sudo cp /home/ubuntu/papernet-deploy/papernet.service /etc/systemd/system/papernet.service
sudo systemctl daemon-reload
sudo systemctl enable --now papernet
sudo systemctl status papernet --no-pager
```

防火墙与云安全组只放行 TCP `8080`。访问：

- 教师端 `http://服务器IP:8080/teacher/`
- 学生端 `http://服务器IP:8080/student/`
- 健康检查 `http://服务器IP:8080/api/v1/health`

根路径没有首页。两边必须同一主机名和同一端口。账号不是 `ubuntu` 时，改 `papernet.service` 里的 `User=` 和路径。

## 2. 预览用编好的静态页，少走 Vite

状态：已执行。

教师机在发现静态页时，同一端口同时提供 `/api`、`/ws`、`/teacher/`、`/student/`，形态与正式部署相同。查找顺序：环境变量 `PAPERNET_UI_DIR`，否则当前目录或 exe 旁边的 `teacher/index.html` 与 `student/index.html`。未找到静态页时仍只提供接口（Docker 里继续由 Nginx 托管页面）。

本环境预览：

```bash
/root/.cargo/bin/cargo build --release -p papernet-teacher
bash scripts/build-web.sh
bash scripts/preview-static.sh
```

默认 `http://127.0.0.1:8088/teacher/` 与 `/student/`。数据目录默认仓库内 `data/`。

## 3. Windows 教室：教师机一个程序，学生用浏览器

状态：已执行（交叉编译脚本与教室包布局）。

教师电脑（Windows 10+ 64 位）跑一个文件夹：`papernet-teacher.exe` + `teacher/` + `student/` + `启动教室.bat`。老师打开 `http://本机IP:8088/teacher/`，学生用浏览器打开同一地址的 `/student/`。学生不用装程序。

`file://` 打开 HTML 访问不了接口。仓库里的 `papernet-student` 是 Linux 无界面客户端。

在本仓库打包（需 `gcc-mingw-w64-x86-64`）：

```bash
bash scripts/pack-windows.sh
```

产物在 `deploy/windows/`（gitignore，不入库）。把整个文件夹拷到教师电脑后双击 `启动教室.bat`。改端口只改 bat 里 `PAPERNET_BIND` 的左边数字对应端口。

## 1.1 手动部署：教师机本机 80，Nginx 对外 8080

教师机只绑 `127.0.0.1:80`，自己提供 `/teacher/`、`/student/`、`/api`、`/ws`。公网打不到 80。

Nginx 不托管静态文件，只在 `8080` 把访问转到本机 80。浏览器仍走同一入口的 `/api` 与 `/ws`（页面需要它们）；这两条路径对外只出现在 8080，不出现在公网 80。

先装 Nginx 并关掉它占用的 80，再启动教师机：

```bash
sudo apt-get update
sudo apt-get install -y nginx

sudo mkdir -p /home/ubuntu/papernet-data
chmod +x /home/ubuntu/papernet-deploy/runtime/papernet-teacher

sudo cp /home/ubuntu/papernet-deploy/nginx.conf /etc/nginx/sites-available/papernet
sudo ln -sf /etc/nginx/sites-available/papernet /etc/nginx/sites-enabled/papernet
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx
```

systemd 服务（账号和路径按实际修改）：

```bash
sudo tee /etc/systemd/system/papernet.service >/dev/null <<'EOF'
[Unit]
Description=PaperNet teacher
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/papernet-deploy/runtime
Environment=PAPERNET_BIND=127.0.0.1:80
Environment=PAPERNET_DATA_DIR=/home/ubuntu/papernet-data
Environment=PAPERNET_UI_DIR=/home/ubuntu/papernet-deploy/runtime
ExecStart=/home/ubuntu/papernet-deploy/runtime/papernet-teacher
Restart=on-failure
AmbientCapabilities=CAP_NET_BIND_SERVICE
CapabilityBoundingSet=CAP_NET_BIND_SERVICE
NoNewPrivileges=true

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now papernet
sudo systemctl status papernet --no-pager
```

防火墙与云安全组只放行 TCP `8080`。访问：

- 教师端 `http://服务器IP:8080/teacher/`
- 学生端 `http://服务器IP:8080/student/`
- 健康检查 `http://服务器IP:8080/api/v1/health`

根路径没有首页。两边必须同一主机名和同一端口。
