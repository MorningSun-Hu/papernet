# 课堂与领取

教师先定员创建课堂，再开领。学生打开 `/student/` 调用 `POST /api/v1/classrooms/join`。课堂码本期不实施，学生加入当前唯一课堂。

领取状态在教师机：`ClaimState`（等待开领、开领中、暂停、满员等）。满员文案：`本课设备已领完，请看教师屏`（`papernet_shared::MSG_CLASSROOM_FULL`）。

已领角色一直占着，断线或心跳超时不会释放。教师在拓扑上「解除绑定」后该角色才能再被领取。waiting 连接在 open-claim 后立即领取。

每个学生页标签都会 join 并占用一个角色。多余标签会把课堂领满。

教师关页后再打开：课堂 ID 在 `localStorage`；没有本地 ID 时走 `GET /api/v1/classrooms/current`。服务重启后 `active_id` 为空，sqlite 里的旧课堂不会自动变成当前课堂。

相关代码：`crates/teacher/src/lib.rs`、`web/shared/claim.ts`。修订记录 `docs/08-前端修订记录.md`。
