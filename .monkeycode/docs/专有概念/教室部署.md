# 教室部署

教室服务器不用 Docker。

教师机：`PAPERNET_BIND=127.0.0.1:80`，`PAPERNET_UI_DIR=`，只提供 `/api` 与 `/ws`。
Nginx：听 8080，`root /var/www/papernet`，托管 `/teacher/` `/student/`，反代 `/api/` `/ws`。
防火墙和安全组只放行 TCP 8080。

页面必须拷到 `/var/www/papernet/`。`www-data` 读不了 `/home/...` 时 `/teacher/` 会 500（Permission denied）。Nginx 配置用 `root` + `try_files`，不要 `alias` 搭配 `try_files`（会重定向循环）。

账号路径按服务器改 `deploy/papernet.service`（仓库默认 `User=ubuntu`）。当前教室机器曾用 `User=service-deploy`、目录 `/home/service-deploy/papernet-deploy`。

目标 Ubuntu amd64。ARM 跑不了这份 Linux 二进制。

Windows 教室：整夹 `deploy/windows/`，教师电脑双击 `启动教室.bat`，学生只用浏览器。`file://` 打开 HTML 访问不了接口。

步骤原文：`docs/09-发布与部署说明.md`、`deploy/Ubuntu-26.04-Nginx部署教程.html`。
