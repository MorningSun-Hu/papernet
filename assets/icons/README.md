# assets/icons

设备图标：路由器、交换机、PC、特殊双口交换机、RJ45 端口。
学生端使用本目录轻量矢量底图与 RJ45 叠加。教师端拓扑使用 `logical/` 示意图标，后换思科图标。

## 目录

| 路径 | 用途 |
| --- | --- |
| `source/` | 用户提供的原图（PNG，部分带参考 SVG） |
| `switch.svg` `router.svg` `nic.svg` `rj45.svg` | 学生端运行时轻量手绘矢量（对照 PNG） |
| `logical/` | 教师端逻辑图标占位，待思科图标替换 |

`source/` 现有文件：

| 文件 | 角色 |
| --- | --- |
| `无网口灰色交换机正面实物图.png` | 交换机 / TAP 底图 |
| `无网口灰色路由器正面实物图.png` | 路由器底图 |
| `网卡正面实物图.png` | PC 底图 |
| `RJ45端口正面实物图.png` | 端口叠加 |

运行时禁止使用 `source/` 内体积过大的参考 SVG。画面规则见 `docs/05-前端界面设计.md`。
