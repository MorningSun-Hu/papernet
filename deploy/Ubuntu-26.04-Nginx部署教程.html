教室服务器部署

教师机只听本机 127.0.0.1:80，提供 /api 和 /ws。Nginx 听 8080，托管 /teacher/、/student/，并把接口转到教师机。不用 Docker。

拷贝

scp -r deploy ubuntu@服务器IP:~/papernet-deploy

安装并启动

sudo apt-get update
sudo apt-get install -y nginx
mkdir -p ~/papernet-data
chmod +x ~/papernet-deploy/runtime/papernet-teacher
sudo mkdir -p /var/www/papernet
sudo cp -a ~/papernet-deploy/runtime/teacher /var/www/papernet/teacher
sudo cp -a ~/papernet-deploy/runtime/student /var/www/papernet/student
sudo cp ~/papernet-deploy/nginx.conf /etc/nginx/sites-available/papernet
sudo ln -sf /etc/nginx/sites-available/papernet /etc/nginx/sites-enabled/papernet
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx
sudo cp ~/papernet-deploy/papernet.service /etc/systemd/system/papernet.service
sudo systemctl daemon-reload
sudo systemctl enable --now papernet
sudo ufw allow 8080/tcp

账号不是 ubuntu 时，先改 papernet.service 里的 User= 和路径。云安全组只放行 TCP 8080，不要放行 80。

访问

谁打开地址
老师http://服务器IP:8080/teacher/
学生http://服务器IP:8080/student/
健康检查http://服务器IP:8080/api/v1/health

根路径没有首页。两边必须同一主机名和同一端口。

维护

sudo journalctl -u papernet -n 100 --no-pager
sudo systemctl restart papernet
sudo systemctl reload nginx

80 被占用时：删掉 Nginx 默认站点后 ss -tlnp | grep ':80'，应只有教师机。

/teacher/ 返回 500、日志 Permission denied：Nginx 工作用户（通常 www-data）读不了部署目录。页面拷到 /var/www/papernet/，不要让 Nginx 直接读 /home/...。无斜杠的 /teacher 会 301 到 /teacher/。
